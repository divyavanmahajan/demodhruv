# Stream 6 - Strategic trend and direction: where the industry is heading

**What is happening:** This stream captures the forward-looking picture: analyst forecasts,
vendor roadmaps, investment flows, and competing visions (human-readable code vs. model-owned
code) so the paper can state the strategic direction and its implications for dependency risk.

## Research questions
- Analyst forecasts: Gartner (e.g. "by 2028 90% of enterprise software engineers will use AI
  code assistants", "AI-native software engineering", predictions on agentic AI project
  cancellations, technical debt forecasts); Forrester; IDC; McKinsey on developer productivity;
  Stack Overflow survey trend lines on adoption and trust (2023-2026); Anthropic Economic Index
  on coding share of usage.
- Market/adoption: Copilot user counts (GitHub/Microsoft earnings statements), Cursor ARR and
  valuation, Claude Code revenue run-rate, OpenAI Codex usage, Anysphere/Cognition/Windsurf
  M&A, enterprise seat adoption.
- Vendor strategic direction: from "assistant" to "agent" to "agent fleets"; Microsoft's
  "agentic DevOps"; GitHub's "Agent HQ" (multi-vendor agents); Anthropic's Claude Code SDK /
  Agent SDK; OpenAI's Codex + AGENTS.md; AWS Kiro spec-driven; Google Antigravity/Jules; the
  push to have agents own the full SDLC (planning, coding, testing, deploy, on-call).
- Competing visions about code itself: (a) code remains a human-readable artefact with humans
  accountable (Google/Thoughtworks position), (b) code becomes an intermediate representation
  regenerated on demand ("software 3.0", Karpathy; "disposable software"; "English as
  programming language"), (c) hybrid: specs/tests/architecture docs become the durable
  artefact. Who argues what and what evidence do they cite?
- Labour and skills direction: hiring trends for junior developers (Stanford 2025 "Canaries in
  the Coal Mine"; Indeed/LinkedIn data), predictions on team size, the "10x team" narrative,
  evidence of layoffs attributed to AI coding.
- Dependency/concentration risk as a strategic theme: concentration of coding-agent market
  among ~5 vendors, model deprecation cycles (e.g. how quickly models are retired), pricing
  volatility, and what this means for code maintained primarily by agents.
