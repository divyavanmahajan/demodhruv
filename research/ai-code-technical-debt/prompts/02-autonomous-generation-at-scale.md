# Stream 2 - Evidence that vendors are generating code with near-autonomous AI, loosely supervised

**What is happening:** This stream establishes the premise of the hypothesis: that Microsoft,
GitHub, AWS, Anthropic, Cursor, OpenAI, Google and others are now producing a large share of
their own and their customers' code with agentic tools under light human supervision.

## Research questions
- Executive statements with numbers: Satya Nadella on % of Microsoft code written by AI (2025);
  Sundar Pichai on >25%/30% of new Google code; Anthropic statements that Claude Code writes
  ~80-90% of Claude Code's own code; Dario Amodei predictions; Mark Zuckerberg on Meta agents;
  Amazon's Andy Jassy on Amazon Q Developer saving "4,500 developer-years" on Java upgrades;
  Cursor claims about Composer/agent usage and share of code accepted; OpenAI Codex usage
  statistics; GitHub Copilot coding agent statistics; any 2026 updates.
- The product shift from autocomplete to autonomous agents: GitHub Copilot coding agent, Claude
  Code (CLI, remote/web), OpenAI Codex (cloud agent), Cursor background agents, AWS Kiro and
  Amazon Q Developer agents, Google Jules / Antigravity, Devin (Cognition), OpenHands. Dates,
  capabilities, and how much human oversight each assumes (e.g. "async", "autonomous",
  "background" wording in their own docs).
- Evidence of how loosely humans supervise: acceptance-rate statistics, "vibe coding"
  (Karpathy Feb 2025) and its adoption in industry; surveys on how often developers read AI
  output (Stack Overflow 2024/2025/2026 developer survey; JetBrains; Google DORA); Anthropic
  Economic Index / "How AI is transforming work at Anthropic" studies on delegation vs
  collaboration; incidents where agents deleted databases or shipped bugs (e.g. Replit agent
  July 2025, Amazon Q extension incident, Google Gemini CLI file deletion).
- Volume: any figures on total AI-authored PRs on GitHub, share of commits by agents, or growth
  in lines of code merged.
